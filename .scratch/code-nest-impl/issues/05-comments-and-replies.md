# 05: 评论与回复

**What to build:** 读者可以对已发布的文章发表评论，也可以在某条评论下发表回复，并可指定回复同一评论下的某个人。评论列表和回复列表都是游标分页，每条评论带回复数。评论者可以删除自己的评论或回复；评论被删除后，如果下面还有回复，这条评论显示为"该评论已删除"，回复继续保留。文章的评论数和评论的回复数随增删变化。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] **comment 表**：`root_id = 0` 表示评论，否则是挂在该评论下的回复；索引 IDX(article_id, root_id, id)。
- [ ] **`POST /articles/{id}/comments`**：对草稿、已删除或不存在的文章发表评论时返回 404。内容不超过 1000 字。
- [ ] **`POST /comments/{id}/replies`**：可以带 `replyToUserId`，这个用户必须是该评论或同一评论下某条回复的作者，否则返回 400。对回复再回复时，仍然挂在同一条评论下，不形成嵌套。
- [ ] **`GET /articles/{id}/comments?cursor=`**：匿名可访问，返回一级评论，每条带回复数，不内嵌回复。
- [ ] **`GET /comments/{id}/replies?cursor=`**：匿名可访问，平铺返回，每条带被回复人的简要信息。
- [ ] **`DELETE /comments/{id}`**：只有本人能删，否则返回 403；软删除。
  - 已删除但仍有回复的评论，在列表里保留位置，内容显示为"该评论已删除"。
  - 已删除且没有回复的评论，不再出现在列表里。
- [ ] **计数**：通过 `CounterApi` 维护。评论增删时文章评论数 ±1；回复增删时评论回复数 ±1，同时文章评论数也 ±1。
- [ ] **`ArticleApi`**：新增批量查询评论摘要，供通知模块使用。
- [ ] **HTTP 测试**：覆盖上述全部行为。
